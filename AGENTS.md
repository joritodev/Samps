# Agents — Samps OS

Antes de planejar ou implementar qualquer coisa neste repositório:

1. Leia `docs/superpowers/plans/2026-08-07-playbook-metodologia.md` (metodologia obrigatória).
2. Leia `docs/superpowers/plans/2026-08-04-roadmap-master.md` (ordem das fases).
3. Abra só o plano da **fatia** da sessão — nunca execute uma fase inteira de uma vez.

## Regras rápidas

- Unidade de trabalho = **1 fatia / 1 PR**.
- Motor padrão com plano detalhado: **subagent-driven-development**.
- Sessão cloud dedicada a uma fatia: **executing-plans**.
- Feature sem design: **brainstorming** → spec → **writing-plans**.
- Bug sem causa óbvia: **systematic-debugging** (não SDD).
- Fase 5 (pesquisa): só documentos; **sem** código de produção.
- Schema / auth / RLS / upload / PII fora do plano → **parar** e replanejar com modelo forte.
- Ledger: `.superpowers/sdd/progress.md`.
- Prompt de abertura: playbook, seção 6.
