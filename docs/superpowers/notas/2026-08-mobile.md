## Atrapalha (corrigido ou mitigado)

| Rota / superfície | Problema | Correção |
|-------------------|----------|----------|
| `/equipe`, `/clientes` | Tabelas sem scroll horizontal útil | `overflow-x-auto` nos wrappers |
| Headers demandas/clientes | Botões sem `flex-wrap` | `flex-wrap` |
| Kanban (demandas, social, design, board, setor) | Scroll horizontal sem snap | `snap-x snap-mandatory` + `snap-start` |
| Filtros do quadro | Larguras fixas `w-40`… | `w-full sm:w-*` |
| Ficha cliente | Tabs longas | `overflow-x-auto` no `TabsList` |
| Escopo de contrato | Grid fixo 3 colunas | `grid-cols-1 sm:grid-cols-[…]` |
| Sheets equipe/ausência | Sem `max-h` / `w-full` | `w-full max-h-[90dvh] overflow-y-auto` |
| Nav links | Toque &lt; 40px | `min-h-10` |
