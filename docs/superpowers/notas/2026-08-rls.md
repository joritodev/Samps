## Migration

## Como rodar antes de cada release

```bash
npm run check:rls
```

Requer `DATABASE_URL` apontando para o banco com migrations aplicadas (incluindo esta). Exit 0 só se todas as linhas forem `OK`.

## Resultado neste ambiente de agent

Banco Neon/`DATABASE_URL` **não disponível** neste VM — o script não foi executado contra dados reais aqui. Após merge:

1. `npx prisma migrate deploy` em Production/Preview  
2. `npm run check:rls` local ou em CI com secret de banco de staging  
3. Smoke: login `cliente@samps.digital` → `/painel-gestao`, `/clientes`, `/demandas` devem redirecionar para `/portal`
